# Bloom

A calm chain-reaction garden. Tap a bud to add a petal; at four petals it blooms and sends a petal along each of its arrows. Line buds up and one drop can bloom half the garden, each flower playing the next note of a melody.

Comparison prototype. See `docs/GDD.md` for the design and `CLAUDE.md` for commands.

```
npm install
npm run dev
```
